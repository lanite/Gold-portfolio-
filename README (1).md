## 🚀 Deploy in Under 5 Minutes

### Files in this folder
```
index.html                   ← the entire website (single file)
IMG-20260227-WA0044.jpg      ← your profile photo
vercel.json                  ← Vercel deployment config
README.md                    ← this file
```

---

### Option A — Deploy to Vercel (recommended, FREE)

1. Go to [github.com](https://github.com) → create a **new repository** (e.g. `lana-portfolio`)
2. Upload all files in this folder to that repo
3. Go to [vercel.com](https://vercel.com) → **New Project** → Import your GitHub repo
4. Click **Deploy** — done! Your site will be live at `https://lana-portfolio.vercel.app`

---

### Option B — GitHub Pages (also FREE)

1. Create a GitHub repo named `lana-portfolio`
2. Upload all files in this folder
3. Go to repo **Settings → Pages**
4. Set source to **main branch / root**
5. Your site goes live at `https://yourusername.github.io/lana-portfolio`
